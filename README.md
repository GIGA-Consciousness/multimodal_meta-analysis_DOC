This repository includes code at the basis of the statistical analysis and the figures part of: "Convergent brain circuits and neurotransmitter systems in disorders of consciousness: a systematic review and meta-analysis" [further details to be added shortly]. 

The code at the basis of the statistical analysis for [Neuromaps Toolbox](https://github.com/netneurolab/neuromaps), running on a high performance computing cluster, is stored in https://github.com/GIGA-Consciousness/neuromaps-cluster

Source data used to generate the figures are available in the original article.

If re-using this code, please cite:
Arianna Sala, Michiel Meys, Naji Alnagger et al. Multimodal meta-analysis of brain integrity in disorders of consciousness, 06 January 2026, PREPRINT (Version 1) available at Research Square [https://doi.org/10.21203/rs.3.rs-8480413/v1]
